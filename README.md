## Introduction
Emoji Encoder is a PoC script used to encode invisible text into emoji characters. This script allows the hiding of ASCII characters through some UTF 
shennanigans. Specifically, it uses the variation selector in Emoji characters, and zero-width characters. This technique can be used in both
stegnography and security testing of LLM-based applications. This app is designed to be a PoC and is intended for learning and teaching. This app is 
not designed to be used for malicious purposes.

## Execution
To run EmoPro, simply clone this repo and run ```python encoder.py```, you will need Python 3.6+ to run the app.
